# Contributing

Thanks for your interest in contributing to Beeswax! ♡

## Reporting a bug

Open an [issue](https://github.com/flourish-today/beeswax/issues) with relevant info.

For security-related issues, [SECURITY.md](SECURITY.md).

## Verifying a build

If you build a release yourself by following [Reproducible builds](PRIVACY.md#reproducible-builds), please share the result in an issue no matter what you got.

## Suggesting a change

Use the issue tracker.
